# Plant Disease Detection 📸🌿

This project is a **Plant Disease Detection system** that uses machine learning / deep learning to classify plant leaf images as healthy or diseased.

The model and code in this repository **work on the Plant Diseases Dataset** from Kaggle:  
https://www.kaggle.com/datasets/smokeyscraper/plant-diseases-dataset

## 📁 Dataset

The dataset contains images of plant leaves labeled with different disease categories and healthy classes. It is used to train and evaluate the model for plant disease classification tasks.

You can download the dataset from Kaggle and place it in the `data/` folder before running the code.

## 🧠 What This Project Does

- Loads plant leaf images
- Preprocesses and augments the data
- Trains a convolutional neural network (CNN) for classification
- Evaluates model performance on test images
- Predicts disease class for new leaf images

## 🛠️ Technologies Used

- OpenCV / PIL
